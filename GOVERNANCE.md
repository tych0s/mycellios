# Governance

Mycellios is currently maintained by the repository owner with contributions
from the community.

## Decisions

Small fixes can be proposed directly through pull requests. Changes to public
protocols, security boundaries, compatibility or project direction should
start with an issue that explains the problem, alternatives and migration
impact. Maintainers make the final decision after public review.

Accepted capabilities must be backed by reproducible evidence. Simulation and
single-host results remain useful engineering evidence, but cannot establish a
physical multi-host claim.

## Maintainers

## Conduct and security
